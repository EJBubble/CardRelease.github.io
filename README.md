# CardRelease
一個以靜態網頁呈現的生日卡片專案。訪客可從首頁選擇卡片；每張卡片會依生日規則自動鎖定與解鎖。

## 功能

- 首頁以大頭貼卡片呈現選項
- 個人卡片可在生日當天自動解鎖
- 非生日期間顯示倒數與鎖定畫面
- 支援預覽參數 `?preview=on`，方便非生日期間檢視頁面
- 靖雯卡片包含互動祝福、相片、影片與禮物選擇流程

## 目錄分類

```text
CardRelease/
├── index.html          # 首頁
├── pages/              # 各人物的卡片頁面
├── assets/
│   ├── css/            # 共用樣式
│   ├── js/             # 年度解鎖與互動腳本
│   ├── images/         # 人物、預覽與相片資源
│   └── media/          # 影片資源
└── README.md           # 專案說明
```

## 本機預覽

在專案根目錄執行：

```bash
python3 -m http.server 4173
```

然後開啟 `http://127.0.0.1:4173/`。

## 年度解鎖規則

- 卡片僅在當地時間的生日當天自動解鎖
- 解鎖時間為生日當天 00:00
- 每年會依設定月日自動計算下一次解鎖時間
- 預覽參數僅供開發與測試使用

## 隱私與維護

本專案的公開說明與目錄分類不包含個人生日、姓名對應、聯絡方式或其他個資。新增內容前，請確認圖片、文字與媒體未含非必要個人資訊。
